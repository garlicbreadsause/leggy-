## Chat with Leggy

To chat with Leggy, the sentient best friend from SMG4:

1. Set your OpenAI API key as an environment variable:
   ```
   export OPENAI_API_KEY='your-api-key-here'
   ```

2. Run the chat:
   ```
   python chat.py
   ```

Leggy will respond in her unique, cute style with short, broken fragments, squeaky sounds, and her love for paninis!

Note: Requires an OpenAI API key for AI-powered responses.
